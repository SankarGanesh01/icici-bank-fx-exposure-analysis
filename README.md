# ICICI Bank Foreign Exchange Exposure Analysis

## Overview

This project investigates the relationship between ICICI Bank's daily stock returns and movements in selected foreign-exchange rates, using Indian equity-market returns as market controls.

The analysis uses R to construct financial time series, estimate multiple linear regression models, conduct diagnostic tests, compare model specifications, and examine changes in estimated currency-return relationships around the COVID-19 period.

**Research period:** January 2019 onward, with the data-download script using the current date as its end date.

## Research Questions

- How are changes in selected FX rates associated with ICICI Bank's stock returns after controlling for broad Indian equity-market movements?
- Do Western currency specifications (USD, GBP and EUR) and Asian currency specifications (AED, CNY and JPY) differ in explanatory fit?
- Does replacing the NIFTY market benchmark with the NIFTY Bank index change the model's explanatory performance?
- How do estimated EUR, GBP and USD coefficients differ before and after the selected COVID-period split?
- Which regression specification offers the better in-sample fit under the selected model-comparison criteria?

## Data and Variables

The data-collection script retrieves daily closing prices from Yahoo Finance using `quantmod`.

| Variable | Source ticker or input | Purpose |
|---|---|---|
| ICICI Bank | `ICICIBANK.NS` | Dependent stock-return series |
| NIFTY 50 | `^NSEI` | Broad-market benchmark |
| NIFTY Bank | `^NSEBANK` | Banking-sector robustness benchmark |
| USD/INR | `USDINR=X` | Western currency specification |
| GBP/INR | `GBPINR=X` | Western currency specification |
| EUR/INR | `EURINR=X` | Western currency specification |
| AED/INR | `AEDINR=X` | Asian currency specification |
| USD/CNY | `USDCNY=X` | Used to derive CNY/INR |
| USD/JPY | `USDJPY=X` | Used to derive JPY/INR |

CNY/INR and JPY/INR are derived using the USD/INR series and the corresponding USD/CNY or USD/JPY series. The script then merges the price series using dates common to all included series.

The regression script also requires a `Tbill_Yield` series for the 91-day Treasury Bill yield. This input must be incorporated into the final analysis dataset; it is not generated by the displayed data-download script.

## Methodology

### 1. Price and return construction

Daily closing prices are converted into log returns:

\[
r_t=\ln(P_t/P_{t-1})
\]

The analysis constructs return series for ICICI Bank, NIFTY 50, NIFTY Bank, and the six currency variables.

### 2. Risk-free-rate adjustment

The script converts the annual Treasury Bill yield into a daily log-rate approximation:

\[
r_{f,t}=\ln\left(1+\frac{y_t/100}{252}\right)
\]

ICICI Bank, NIFTY 50 and NIFTY Bank returns are then adjusted by the daily risk-free rate to create excess-return variables.

### 3. Regression specifications

**Western currency model**

\[
R_{\text{ICICI}}-R_f =
\alpha+\beta_m(R_{\text{NIFTY}}-R_f)
+\beta_1r_{\text{USD}}
+\beta_2r_{\text{GBP}}
+\beta_3r_{\text{EUR}}+\epsilon
\]

**Asian currency model**

\[
R_{\text{ICICI}}-R_f =
\alpha+\beta_m(R_{\text{NIFTY}}-R_f)
+\beta_1r_{\text{AED}}
+\beta_2r_{\text{CNY}}
+\beta_3r_{\text{JPY}}+\epsilon
\]

**NIFTY Bank robustness model**

The Western currency variables are retained, while the broad-market excess return is replaced with the NIFTY Bank excess return.

The analysis also estimates a USD-only model and separate Western-model regressions for pre- and post-COVID subsamples.

### 4. Diagnostic tests

The main Western model is evaluated using:

- Variance Inflation Factor (VIF) for multicollinearity.
- Breusch–Pagan test for heteroscedasticity.
- Durbin–Watson test for residual autocorrelation.

### 5. Model comparison

The analysis compares in-sample \(R^2\) values across the Western, Asian and NIFTY Bank specifications. AIC is also used to compare the Western and Asian models.

## Reported Model Comparisons

The supplied \(R^2\) chart displays the following in-sample values:

| Model | Displayed \(R^2\) |
|---|---:|
| Western | 0.578 |
| Asian | 0.579 |
| NIFTY Bank | 0.768 |

The AIC chart displays approximately −9,308 for the Western model and −9,311 for the Asian model. The difference is small.

These are reported chart values and should be confirmed against the final regression output. A higher \(R^2\) does not establish causality or out-of-sample predictive performance, and AIC comparisons require compatible estimation samples and response definitions.

## Limitations

- The regression coefficients measure conditional associations between stock returns and FX-rate movements. They do not directly measure ICICI Bank's net foreign-currency assets, liabilities, or regulatory FX exposure.
- The pre/post-COVID coefficient comparison is descriptive unless supported by a formal structural-break test.
- The current script uses a fixed split date of 1 April 2020; this is an analytical choice, not a definitive date for every COVID-related market effect.
- Daily closing-price data may not capture intraday exposure or the bank's underlying foreign-currency positions.
- Results depend on the quality of the FX series, the risk-free-rate input, the common-date merge, and the regression specification.
- In-sample fit does not establish predictive performance or an economically exploitable trading relationship.

## Reproducibility

1. Install R and the packages listed in `requirements.R`.
2. Obtain the required market data and the 91-day Treasury Bill yield series.
3. Run the data-collection script.
4. Add the Treasury Bill yield to the analysis dataset and ensure dates and column names match the regression script.
5. Run the regression and diagnostic analysis.
6. Compare the resulting estimates with the published figures.

The pipeline should be tested from a clean environment before the repository is described as fully reproducible.
